# Ancestralidade Viva 🌿

Este projeto é uma plataforma digital dedicada à valorização e comercialização de arte e cultura dos povos originários.

## 🏹 Sobre o Projeto
O site foi desenvolvido para conectar a sabedoria das matas à civilização moderna, oferecendo peças autênticas como grafismos tradicionais e biojoias sustentáveis.

## 🛍️ Funcionalidades
- Catálogo de produtos com fotos reais.
- Integração direta com WhatsApp para vendas.
- Navegação por abas (Início, Produtos, História, Contato).

## 🛠️ Tecnologias
- HTML5
- CSS3
